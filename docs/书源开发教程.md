# 香色闺阁书源开发教程（公众号配套）

> 目标读者：会用香色闺阁、但没写过书源的用户
> 配套工具：开源项目 xiangseSkill（GitHub: cloudmantou/xiangseSkill）

## 一、书源到底是什么？

书源是一段 JSON 规则，告诉香色闺阁：

- 去哪个网站搜索（`searchBook`）
- 怎么打开书籍详情（`bookDetail`）
- 怎么抓取章节目录（`chapterList`）
- 怎么读取正文（`chapterContent`）
- 有哪些分类可以浏览（`bookWorld`）

每个动作由三部分组成：

1. **requestInfo**：怎么请求（URL、POST 参数、@js 动态拼接）
2. **解析规则**：从页面里抓什么（XPath 或 JSONPath）
3. **分页/编码**：下一页怎么找、GBK 怎么解

## 二、手写 vs AI 生成

手写书源的难点不在语法，而在**每个网站都不一样**：

- 有的网站书名里有高亮标签（`<span>` 嵌套），直接抓会多字
- 有的封面是懒加载（`data-src`），抓 `src` 是空的
- 有的章节分页带 `_2` 后缀
- 有的搜索被关闭、有的反爬 403

AI + Skill 工作流把这些都变成了**自动化的验证关卡**，让 AI 先写、机器先验、人最后确认。

## 三、完整流程演示

### 环境准备

```bash
git clone git@github.com:cloudmantou/xiangseSkill.git
cd xiangseSkill
cd tools/validator && npm install && cd ../..
# Python 3.9+ / Node 18+ 即可，Go 仅在需要时
```

### 第一步：让 AI 写书源

```text
请使用 $xbs-booksource-workflow，并按 skills/xbs-booksource-workflow/SKILL.md 执行。
site=https://www.wcshuba.com/
task_type=new_source
keyword=腐朽世界
```

### 第二步：AI 做了什么（你可以对照验证）

**1. 抓四个真实页面样本**

```bash
python3 tools/scripts/pipeline_new_source.py fetch-samples \
  --site https://www.wcshuba.com/ \
  --search-url 'https://www.wcshuba.com/search/?searchkey=%E8%85%90%E6%9C%BD%E4%B8%96%E7%95%8C' \
  --detail-url 'https://www.wcshuba.com/book/3254.html' \
  --list-url 'https://www.wcshuba.com/chapterlist/3254.html' \
  --content-url 'https://www.wcshuba.com/read/3254/1870737.html' \
  -o tools/verification/samples/wcshuba \
  --keyword 腐朽世界
```

**2. 生成书源 JSON**（核心内容示意）

```json
{
  "無錯書吧-v0811": {
    "sourceName": "無錯書吧",
    "sourceUrl": "https://www.wcshuba.com/",
    "sourceType": "text",
    "enable": 1,
    "weight": "9999",
    "searchBook": {
      "actionID": "searchBook",
      "parserID": "DOM",
      "requestInfo": "@js:return {'url': config.host + '/search/?searchkey=' + encodeURIComponent(params.keyWord), 'httpHeaders': config.httpHeaders};",
      "list": "//div[contains(@class,'content')]//dl",
      "bookName": "//dt/a//text()||@js:return String(result || '').replace(/\\s+/g, ' ').trim();",
      "detailUrl": "//dt/a/@href"
    },
    "bookDetail": { "...": "og:novel meta 系列" },
    "chapterList": { "...": "rel='chapter' 链接 + 目录分页" },
    "chapterContent": { "...": "#booktxt 容器 + 同章分页守卫" },
    "bookWorld": { "玄幻": { "...": "分类浏览" }, "...": "共 10 个分类" }
  }
}
```

**3. 四层验证**（一条命令跑完）

```bash
python3 tools/scripts/pipeline_new_source.py run \
  -i tools/verification/wcshuba_source.json \
  --fixtures tools/verification/samples/wcshuba \
  --keyword 腐朽世界 \
  --live \
  --report-dir tools/verification/out
```

输出 `PIPELINE_STATUS: pass` 表示四层全过；输出 `fail/blocked` 会给出具体原因。

**4. 打包成 XBS**

```bash
python3 tools/scripts/xbs_tool.py json2xbs \
  -i tools/verification/wcshuba_source.json \
  -o tools/verification/wcshuba_source.xbs
```

### 第三步：导入香色闺阁

1. 将 `.xbs` 传到手机（微信文件传输助手 / 隔空投送均可）
2. 香色闺阁 → 书源管理 → 右上角「导入」→ 选择文件
3. 确认导入，书源出现在列表即成功

### 第四步：人工验收（30 秒）

1. 搜索你设定的关键词 → 能出书
2. 打开详情 → 封面/作者/简介齐全
3. 打开目录 → 章节列表完整、翻页正常
4. 打开正文 → 内容可读、无广告残留
5. **书源管理 → 编辑 → 直接保存**（不改内容）→ 不闪退

第 5 步最容易被忽略，但它是「导入能用」和「真正交付」的分水岭。

## 四、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 搜索没结果 | 网站关闭了搜索 | 书源已降级为分类浏览（见 bookWorld） |
| 正文空白 | 反爬/需要 WebView | 换 HTTP 直连可用的网站 |
| 保存闪退 | weight/requestFilters 类型问题 | 用 `check-editor` 检查后修复 |
| 分类点不动 | PlayCover（Mac 模拟 iOS）兼容边界 | 在 iOS 真机使用；规则本身经 App 测试面板验证 |
| GBK 乱码 | 网站用 GBK 编码 | 设置 `responseEncode: "2147485234"` |

## 五、进阶：自己改规则

- 字段语法：`"//xpath||@js:return ...;"` 表示「先按 XPath 取，再交给 JS 处理」
- `params.filter` 是用户点分类时传入的分类值
- 分页守卫：`nextPageUrl` 里用 `params.responseUrl` 对比当前页，防止翻页翻到别的章节
- 详细契约见仓库 `skills/xbs-booksource-workflow/references/xbs-2561-contract.md`
